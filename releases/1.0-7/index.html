MarginMail 1.0 (7)

Mon, Nov 9 · Beta

MarginMail now names each account by its own service, so a Microsoft 365 account no longer reads as Gmail.

Also in this build

  • Settings › Accounts names the service each account uses.
  • Search says which accounts it can look through on the server.
